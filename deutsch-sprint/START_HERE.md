# 从今天开始 · W0 诊断与工具准备

打开 [P6 冲刺仪表盘](index.html)。首次使用时，页面会让你选择实际起始日，默认今天；已有记录不会被覆盖。**不需要先手动修改日期。** W1 从“起始日 + 2 天”当日或之后的第一个周一开始，所以 W0 会是 2–8 天；之后每周按周一到周日计算。W0 前三天完成下面的诊断，其余天作为进入第一个完整周前的缓冲时间。

先确认工具能打开：P1 直接精读一篇 B2 课件；P3/P4 复制提示词到你使用的对话工具；P5 没有本地模型时先做手动听写；P7 是缩小版练习，不是完整模考。

## W0 第 1 天 · 基线与工具

- [ ] 联系 2–3 位德语导师，预约第 2–4 天的试课；确认是否能做诊断与持续纠错，再决定是否固定合作。
- [ ] 安装 Anki 并开启 FSRS。新卡量先设得保守，以能稳定完成复习为准。
- [ ] 只做 1 套 Goethe 官方 B2 Lesen + Hören 作为基线；限时完成、不查词典，分别记录结果和错题。
- [ ] 在 P6 记录 B2 基线及计划起始日。起始日首次选择后，仪表盘会自动计算 W0/W1。

## W0 第 2 天 · 写作与盲读

- [ ] 完成一篇德语写作基线并保留原稿；可用 P4 做提示式批改后自行订正。
- [ ] 只有当 B2 阅读和听力基线**各自都达到 70%**，才做 1 个 C1 单项试做；不再额外消耗一套完整官方模考。
- [ ] 从 [P1 精读器](p1-reader/index.html) 选择 B2 文章盲读，记录理解难点与可复用词块。

## W0 第 3 天 · 口语诊断与词块

- [ ] 用已预约的导师试课或 AI 语音对练完成口语诊断；不要求先找到语伴。
- [ ] 建立四项技能基线：阅读/听力记录百分比，写作/口语记录评估等级、评价者和日期。它们仅用于个人追踪。
- [ ] 从 B2 盲读、听力和错误中整理首批词块卡，用 P2 导出并导入 Anki。
- [ ] 记下本周最需要改进的两项技能和下一周能执行的练习。

## W1 起的日常节奏 · 周一至周六

| 时间 | 学习块 |
| --- | --- |
| 08:30 | Anki 复习 + 新卡 · 60 分钟 |
| 09:45 | 精读 + 本周语法 · 120 分钟 |
| 12:00 | 口语练习 · 60 分钟；每周安排真人交流和 AI 暖身/对练 |
| 14:30 | 精听 + 跟读 + 复述 · 60 分钟 |
| 15:45 | 写作 + 批改 + 重写 · 90 分钟 |

每天从 P6 总览查看本周主题与五项今日任务，完成后勾选并记录实际分钟数。周日为当周最后一天：做轻量输入、周复盘和 JSON 备份。休息不计入主动学习时间；学习块之间留出休息。

## 每周日复盘

- 在 P6「周复盘」查看对应周一至周日的记录、主动学习时间、口语分钟、新词块、Anki 保持率和规则三态。
- **固定导出一次 P6 JSON 备份**，保存到不会随浏览器缓存一起清理的位置，并确认页面更新了上次导出时间。
- 连续两周同类错误各出现至少 5 次，就安排 3 天专项练习。
- W4、W9、W13 核对 P6 内部门槛；它们不是 Goethe 官方分数或通过判断。写作与口语记录等级、评价者和日期。
- W6–W8 查所在地考点、报名截止和用途方认可的证书类型；以对应考点当期信息为准。

## 官方整套模考保留

W0 只用 1 套官方 B2 阅读 + 听力做基线；基线达到条件后最多补做 1 个 C1 单项。尽量为 W10–W13 留下至少 2 套未做过的完整模考；先在 Goethe 官网确认你报考版本实际可用的套数，本工具没有核实该数量。若官方完整材料不足 2 套，保留所有未做过的官方材料，再补充来源可靠的完整练习并注明非官方；同一套题重复练习不能算成两套独立模考。

## 将 P1 词块交给 Anki

在工具包目录运行（只需 Python 标准库）：

```bash
python3 anki-factory/anki_factory.py p1-reader/lessons.json --output anki-factory/my-export --stats
```

也可用 P1 导出的单篇 JSON 只制作当天学过的文章。按 [P2 导入说明](anki-factory/README.md) 导入 CSV；不要在第一天一次学完所有新卡。
