# 从今天开始 · W0 诊断与装机

按计划制定日 2026-10-23 排定前三天；W1 从 2026-10-26（周一）开始。每日打卡请用 [冲刺仪表盘](index.html)。

## 2026-10-23 · 第 1 天

- [ ] 在仪表盘设置中确认起始日为 2026-10-23。
- [ ] 计时完成 Goethe B2 Modelltest 的 Lesen 与 Hören，不查词典，记录原始结果和错误类型。
- [ ] 完成 Anki 安装与 FSRS 设置；新卡先从每天 25 张开始，保持率目标先设 0.85。
- [ ] 用 P4 模板给一篇旧作文或当天写作建立基线；保留原稿，不直接覆盖。

## 2026-10-24 · 第 2 天

- [ ] 计时完成 Goethe C1 Modelltest 的 Lesen 与 Hören；记录分项结果和主要失分原因。
- [ ] 完成一篇 C1 写作基线，可用 P4 做第一轮“提示式”批改并自己订正。
- [ ] 从 [P1 精读器](p1-reader/index.html) 完成一篇盲读，记录自测分数。

## 2026-10-25 · 第 3 天

- [ ] 录一段 5 分钟德语独白，并与语伴做 15 分钟讨论；保存录音。
- [ ] 建立四项技能雷达：阅读、听力写百分比；写作记录导师/AI 评语区间；口语记流利度与错误类型。
- [ ] 试约 2–3 位愿意强制纠错、提供 5 条优先修正点并维护共享错误日志的导师；先试课，不承诺固定课时。
- [ ] 从前三天的文本和错误中建立首批词块卡，周一开始用 P2 导出并导入 Anki。

## W1 每日节奏 · 周一至周六

| 时间 | 学习块 |
| --- | --- |
| 08:30 | Anki 复习 + 新卡 · 60 分钟 |
| 09:45 | 精读 + 本周语法 · 120 分钟 |
| 12:00 | 口语练习 · 60 分钟；每周 4 天真人，2 天 AI 暖身/对练 |
| 14:30 | 精听 + 跟读 + 复述 · 60 分钟 |
| 15:45 | 写作 + 批改 + 重写 · 90 分钟 |

散步、做饭和晚间可听德语 ≥90 分钟，不计入主动学习时间。每块结束后留至少 15 分钟休息；周日只做 Anki、轻松输入和 30 分钟复盘。

## 每周复盘

- 每周日打开仪表盘「周复盘」，记录主动小时、口语分钟、新词块数和保持率。
- 连续两周同类错误各出现至少 5 次，就按计划做 3 天专项。
- W4、W9、W13 按仪表盘关卡逐项核对；W13 未达到连续两套全项目标时，顺延一个考期。
- W6–W8 查所在地考点、报名截止和用途方认可的证书类型。地点与证书用途需要你本人提供，仪表盘不会替你猜测。
