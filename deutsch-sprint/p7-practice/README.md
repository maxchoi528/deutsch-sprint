# P7 · C1 补充模考

`index.html` 是独立离线练习页，内容源为 `exam.json`，格式见 `exam.schema.json`。修改内容后运行 `python3 build.py` 重新嵌入 JSON 并生成页面。

## 当前练习集

- **Lesen**：原创公共图书馆评论、5 道理解题与证据句；限时 65 分钟。
- **Hören**：原创虚构市民对话说明、5 道理解题与证据句；限时 40 分钟。可使用设备的德语系统语音朗读文本，提交后显示脚本。
- **Schreiben**：1 个论坛观点帖任务和 1 个正式消息任务；各限时 75 分钟，提供要点、字数统计和参考结构。
- **Sprechen**：5 张观点卡，每张含两个相反角度；限时 20 分钟。

## 使用方法

1. 直接打开 `index.html`，选择一个模块并点击「开始限时练习」。
2. 计时按绝对截止时间继续运行，刷新或切换模块不会暂停；到时自动提交。提交后可查看答案、证据句或写作结构。
3. 阅读和听力按正确题数自动计分。写作只统计词数，口语只记录练习计时和自查；语言质量请交给 P4 或导师。
4. 每个模块的数据保存在当前浏览器，可导出练习记录 JSON。重置会清除该模块当前作答并要求确认。

## 三个示例场景

- 限时完成阅读集后查看正确答案和证据句。
- 用系统德语语音播放听力脚本，再完成自动计分题目。
- 写论坛观点帖并查看覆盖要点和参考结构，随后用 P4 批改。

## 已知限制

- 原创补充材料不复制官方 Modelltest，也不代表官方题目或分数标准。
- 只有客观阅读/听力题自动计分；写作与口语无法由本页可靠地自动评定语言水平。
- 听力朗读依赖设备提供的德语系统语音；不同设备的语音可能使用在线服务。没有德语语音时，可请他人朗读或使用你有权使用的音频材料。
- 所有进度只保存在本机浏览器，没有同步；录入的作文和笔记请按需导出备份。
- 模块时长按计划给出的考试时长设置；不同考点、考试版本或任务组合可能不同。
