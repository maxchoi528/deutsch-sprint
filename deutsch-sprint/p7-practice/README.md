# P7 · C1 补充练习

`index.html` 是独立离线练习页，内容源为 `exam.json`，格式见 `exam.schema.json`。修改内容后运行 `python3 build.py` 重新嵌入 JSON 并生成页面。

## 当前练习集

- **Lesen**：原创公共图书馆短文和 5 道理解题；默认练习 20 分钟。数据同时记录 65 分钟参考值，但官网时长尚未联网核实。
- **Hören**：原创虚构双人对话和 5 道理解题；默认练习 15 分钟。数据同时记录 40 分钟参考值，但官网时长尚未联网核实。
- **Schreiben**：两项任务共用一个 75 分钟倒计时；也可切换到逐项自定义计时模式。75 分钟参考值尚未联网核实，自定义分配只用于个人练习。
- **Sprechen**：5 张观点卡，每张含两个相反角度；限时 20 分钟。

页面会明确提示：这是缩小版练习，不是整套模考，也不用于判断考试水平。阅读、听力默认时间用于完成本页当前内容，不模拟完整考试模块。

## 使用方法

1. 直接打开 `index.html`，选择模块并点击「开始限时练习」。
2. 计时按绝对截止时间继续运行，刷新或切换模块不会暂停；到时自动提交。Schreiben 默认两项共享 75 分钟；自定义模式会按设置依次倒计时。
3. 阅读和听力按正确题数自动计分。写作只统计词数，口语只记录练习计时和自查；语言质量请交给 P4 或导师。
4. 每个模块的数据保存在当前浏览器，可导出练习记录 JSON。旧版两个独立写作模块的作文草稿会迁入新写作模块；旧的独立计时不会合并进共享计时。
5. Hören 使用系统语音合成。若检测到两种德语语音，会给 Sprecher A/B 分别选择语音；否则用一种语音并显示提示。

## 已知限制

- 德语材料为 AI 生成的原创练习，不复制官方 Modelltest，也不代表官方题目或分数标准。
- P7 只包含缩小版的阅读、听力练习与写作/口语任务，不是完整模考，不用于推断考试水平。
- `official_duration_minutes` 是供后续核实的参考字段；本任务遵守离线要求，未联网检查 Goethe 官网，界面也标为“待核实”。请以你报考版本的 Goethe 官网信息为准。
- Hören 由浏览器调用设备系统语音朗读脚本，**不是真实录音**；语音音色与可用性随设备变化，部分系统语音可能依赖在线服务。单一语音回退时，对话角色区分会减弱。
- 只有客观阅读/听力题自动计分；写作与口语无法由本页可靠地自动评定语言水平。
- 所有进度只保存在本机浏览器，没有同步；录入的作文和笔记请按需导出备份。
